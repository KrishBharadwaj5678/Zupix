# 🖐️ Zupix

Zupix は、Python ベースの仮想ズームシステムで、手のジェスチャーを使用してリアルタイムで画像を拡大・縮小します。

![ZupixDemo](https://github.com/KrishBharadwaj5678/Zupix/raw/main/ZupixDemo.gif)

## ✨ 特徴

| 機能             | 説明                     |
| -------------- | ---------------------- |
| 📷 手の検出        | 両手をリアルタイムで追跡           |
| 🤏 ジェスチャーズーム   | ピンチジェスチャーで拡大・縮小        |
| 🖼️ 画像ズーム      | 指の間隔に応じて画像をズーム         |
| 🖥️ インタラクティブUI | シンプルで使いやすいユーザーインターフェース |
| 🔁 リアルタイムズーム追跡 | ズームレベルを継続的に更新          |
| ⚡ 高速・軽量        | リアルタイム処理向けに最適化         |
| 🧩 カスタマイズ可能    | 簡単に変更・拡張可能             |

---

## 🛠️ 技術スタック

| 技術            | 説明               |
| ------------- | ---------------- |
| 🐍 Python     | メインプログラミング言語     |
| 📷 OpenCV     | 画像処理およびビデオ入力     |
| 🖐️ MediaPipe | 手の追跡とジェスチャー認識    |
| 🧩 CvZone     | コンピュータビジョン開発を簡素化 |

## 📦 インストール

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/Zupix.git
```

### 2️⃣ プロジェクトフォルダへ移動

```bash
cd Zupix
```

### 3️⃣ 依存関係をインストール

```bash
pip install -r requirements.txt
```

### 4️⃣ アプリケーションを実行

```bash
python app.py
```
