# 🖐️ Zupix

Zupix это виртуальная система масштабирования на базе Python, которая использует жесты рук для увеличения и уменьшения изображения в реальном времени.

![ZupixDemo](https://github.com/KrishBharadwaj5678/Zupix/raw/main/ZupixDemo.gif)

## ✨ Возможности

| Возможность                                 | Описание                                                                |
| ------------------------------------------- | ----------------------------------------------------------------------- |
| 📷 Обнаружение рук                          | Отслеживание обеих рук в реальном времени                               |
| 🤏 Масштабирование жестами                  | Жест «щипок» для увеличения и уменьшения                                |
| 🖼️ Масштабирование изображения             | Изменяет масштаб изображения в зависимости от расстояния между пальцами |
| 🖥️ Интерактивный интерфейс                 | Простой и удобный пользовательский интерфейс                            |
| 🔁 Отслеживание масштаба в реальном времени | Непрерывное обновление уровня масштабирования                           |
| ⚡ Быстрый и лёгкий                          | Оптимизирован для работы в реальном времени                             |
| 🧩 Настраиваемость                          | Легко изменять и расширять                                              |

## 📦 Установка

### 1️⃣ Клонируйте репозиторий

```bash
git clone https://github.com/KrishBharadwaj5678/Zupix.git
```

### 2️⃣ Перейдите в папку проекта

```bash
cd Zupix
```

### 3️⃣ Установите зависимости

```bash
pip install -r requirements.txt
```

### 4️⃣ Запустите приложение

```bash
python app.py
```
