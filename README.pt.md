# 🖐️ Zupix

O Zupix é um sistema virtual de zoom baseado em Python que utiliza gestos com as mãos para ampliar e reduzir uma imagem em tempo real.

![ZupixDemo](https://github.com/KrishBharadwaj5678/Zupix/raw/main/ZupixDemo.gif)

## ✨ Funcionalidades

| Funcionalidade                   | Descrição                                                    |
| -------------------------------- | ------------------------------------------------------------ |
| 📷 Detecção de Mãos              | Rastreia ambas as mãos em tempo real                         |
| 🤏 Zoom por Gestos               | Gesto de pinça para ampliar e reduzir                        |
| 🖼️ Zoom de Imagem               | Ajusta o zoom da imagem com base na distância entre os dedos |
| 🖥️ Interface Interativa         | Interface simples e intuitiva                                |
| 🔁 Rastreamento Contínuo de Zoom | Atualiza continuamente o nível de zoom                       |
| ⚡ Rápido e Leve                  | Otimizado para uso em tempo real                             |
| 🧩 Personalizável                | Fácil de modificar e expandir                                |

---

## 🛠️ Tecnologias Utilizadas

| Tecnologia    | Descrição                                  |
| ------------- | ------------------------------------------ |
| 🐍 Python     | Linguagem principal de programação         |
| 📷 OpenCV     | Processamento de imagem e captura de vídeo |
| 🖐️ MediaPipe | Rastreamento de mãos e detecção de gestos  |
| 🧩 CvZone     | Simplifica tarefas de visão computacional  |

## 📦 Instalação

### 1️⃣ Clone o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/Zupix.git
```

### 2️⃣ Navegue até a Pasta do Projeto

```bash
cd Zupix
```

### 3️⃣ Instale as Dependências

```bash
pip install -r requirements.txt
```

### 4️⃣ Execute a Aplicação

```bash
python app.py
```
